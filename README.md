# OUTPOST ZERO — SURVIVAL PROTOCOL

**OUTPOST ZERO** — динамичный 2D-шутер с видом сверху, разработанный на Python с использованием Pygame. Окажись в опасной зоне, сражайся с волнами противников, собирай ресурсы, улучшай свои характеристики и постарайся продержаться как можно дольше.

Тебя ждут три вида оружия, несколько типов врагов, мощные боссы, система уровней, случайные улучшения, процедурные звуковые эффекты и атмосферная научно-фантастическая музыка.

**Главная цель — выжить, уничтожать противников и установить новый рекорд!**

## Особенности

- Динамичные сражения с постепенно усложняющимися волнами врагов.
- Три вида оружия с разными характеристиками и отдельными запасами боеприпасов.
- Три обычных типа противников и отдельный тип босса.
- Босс появляется каждые пять волн.
- Система опыта и повышения уровня персонажа.
- Шесть видов улучшений, влияющих на характеристики игрока.
- Аптечки, боеприпасы и информационные ядра, разбросанные по карте.
- Рывок для быстрого перемещения и уклонения от атак.
- Противники с разными скоростями, запасом здоровья и поведением.
- Стрельба с разбросом, пробиванием целей и визуальными эффектами.
- Частицы, гильзы, всплывающие числа урона и тряска экрана.
- Фоновая музыка и звуковые эффекты, создаваемые непосредственно кодом.
- Интерфейс с информацией о здоровье, оружии, боеприпасах и противниках.
- Сохранение лучшего результата между запусками игры.

## Игровой процесс

Игровой мир представляет собой большую арену, на которой противники появляются по краям карты и постепенно приближаются к игроку.

Каждая новая волна увеличивает количество противников и усложняет сражения. Чтобы выжить, необходимо постоянно двигаться, следить за боеприпасами, выбирать подходящее оружие и собирать полезные предметы.

За уничтожение врагов игрок получает очки и опыт. Накопив достаточно опыта, можно повысить уровень и выбрать одно из трёх случайно предложенных улучшений.

Каждая пятая волна сопровождается появлением босса — более сильного противника с большим запасом здоровья и усиленными атаками.

**Основные задачи игрока:**

- Уничтожать противников и проходить новые волны.
- Не допускать полного истощения здоровья.
- Следить за патронами и вовремя перезаряжаться.
- Использовать рывок, чтобы избегать опасных ситуаций.
- Собирать ресурсы и повышать уровень.
- Побеждать боссов и улучшать свой рекорд.

## Управление

| Клавиша / кнопка | Действие |
|---|---|
| `W`, `A`, `S`, `D` | Передвижение персонажа |
| `↑`, `←`, `↓`, `→` | Альтернативное управление движением |
| Мышь | Прицеливание |
| Левая кнопка мыши | Стрельба |
| `R` | Перезарядка оружия |
| `1` | Штурмовая винтовка |
| `2` | Дробовик |
| `3` | Рельсовый пистолет |
| `Left Shift` / `Right Shift` | Рывок |
| `P` / `Esc` | Пауза или продолжение игры |
| `Enter` | Начать игру, перезапустить её или возобновить после паузы |
| `Space` | Начать игру с главного меню или заново после поражения |
| `Q` | Выход из игры |

Во время повышения уровня клавиши `1`, `2` и `3` используются для выбора одного из трёх улучшений.

## Оружие

В игре доступны три вида оружия. У каждого собственные характеристики, размер магазина, скорость стрельбы и запас боеприпасов.

### 1. ASSAULT RIFLE — штурмовая винтовка

Универсальное оружие для большинства ситуаций.

- Урон: 24 за попадание.
- Размер магазина: 18 патронов.
- Запас боеприпасов: 90.
- Перезарядка: 1,1 секунды.
- Интервал между выстрелами: 0,13 секунды.

Винтовка подходит для продолжительного ведения огня и уничтожения обычных противников на расстоянии.

### 2. SCATTERGUN — дробовик

Оружие для нанесения высокого урона за один выстрел на близкой дистанции.

- Урон: 14 за попадание.
- Количество дробин: 6 за выстрел.
- Размер магазина: 8 патронов.
- Запас боеприпасов: 40.
- Перезарядка: 1,45 секунды.
- Интервал между выстрелами: 0,48 секунды.

Дробовик выпускает несколько снарядов с разбросом. Если несколько дробин попадают в одну цель, суммарный урон значительно увеличивается.

### 3. RAIL PISTOL — рельсовый пистолет

Мощное оружие для точных выстрелов по опасным целям.

- Урон: 58 за попадание.
- Размер магазина: 7 патронов.
- Запас боеприпасов: 35.
- Перезарядка: 1,3 секунды.
- Интервал между выстрелами: 0,52 секунды.

Снаряды рельсового пистолета способны пробивать одну дополнительную цель, позволяя поражать нескольких противников, расположенных на одной линии.

**Важно:** боеприпасы каждого оружия учитываются отдельно. Использование патронов одного оружия не уменьшает запас другого.

Характеристики оружия могут изменяться благодаря улучшениям во время игры.

## Противники и боссы

В OUTPOST ZERO противники отличаются скоростью передвижения, запасом здоровья, уроном и поведением в бою.

### DRONE — дрон

Базовый противник, который преследует игрока и наносит урон при столкновении.

- Начальное здоровье: 100.
- Скорость: 105 единиц в секунду с небольшим увеличением в зависимости от волны.
- Урон при столкновении: 15.

Дроны встречаются на протяжении всей игры и становятся опаснее по мере увеличения номера волны.

### RUNNER — быстрый противник

Быстрый враг, способный быстро сокращать расстояние до игрока.

- Начальное здоровье: 42.
- Скорость: 180 единиц в секунду.
- Урон при столкновении: 12.

С увеличением номера волны здоровье и скорость бегунов растут. Их высокая скорость заставляет игрока постоянно менять позицию.

### SHOOTER — стрелок

Противник дальнего боя, который старается удерживать дистанцию и атакует игрока снарядами.

- Начальное здоровье: 75.
- Скорость: 75 единиц в секунду.
- Урон снаряда: 10.

Стрелки приближаются, если игрок находится слишком далеко, и отступают, когда он подходит слишком близко. Они требуют особого внимания, поскольку могут атаковать на расстоянии.

### BOSS / ELITE — босс

Мощный противник, появляющийся каждые пять волн.

- Начальное здоровье: 650.
- Скорость: 68 единиц в секунду.
- Урон при столкновении: 24.
- Урон обычного снаряда: 24.
- Дополнительная веерная атака: три снаряда с уроном 13 каждый.

Здоровье босса увеличивается с номером волны. Он обладает увеличенной моделью, отдельной полосой здоровья и более сильными атаками.

Победа над боссом приносит больше очков и опыта, а также с высокой вероятностью оставляет полезный предмет.

## Прокачка и улучшения

За уничтожение противников игрок получает опыт. Когда накопленного опыта достаточно для повышения уровня, игра приостанавливает сражение и предлагает выбрать одно из трёх случайных улучшений.

Каждый следующий уровень требует больше опыта, поэтому для дальнейшей прокачки необходимо уничтожать всё больше противников.

Доступны шесть улучшений:

| Улучшение | Эффект |
|---|---|
| **HIGH CALIBER** | Увеличивает урон оружия на 8 единиц |
| **REINFORCED ARMOR** | Увеличивает максимальное здоровье на 25 и восстанавливает до 40 HP |
| **OVERDRIVE** | Увеличивает скорость передвижения на 22 единицы в секунду |
| **TARGETING AI** | Увеличивает шанс критического попадания на 8 процентных пунктов |
| **EXTENDED MAG** | Увеличивает вместимость магазинов всех видов оружия на 5 патронов |
| **NANITE LEECH** | Позволяет восстанавливать 4 HP за каждое убийство |

### Как выбирать улучшения

- Если противников становится слишком много, увеличение урона помогает быстрее уничтожать цели.
- Если здоровье быстро заканчивается, усиленная броня повышает выживаемость.
- Увеличение скорости помогает уклоняться от противников и менять позицию.
- Повышенный шанс критического попадания увеличивает вероятность более сильных попаданий.
- Увеличенные магазины позволяют реже перезаряжаться.
- Восстановление здоровья за убийства помогает дольше оставаться в бою.

Выбирай улучшение клавишей `1`, `2` или `3` в соответствии с предложенными вариантами.

## Ресурсы и предметы

Во время игры полезные предметы появляются в разных местах карты. Они также могут выпадать после уничтожения противников.

### MEDKIT — аптечка

- Восстанавливает 35 единиц здоровья.
- Не может увеличить здоровье выше максимального значения.
- Если здоровье уже максимальное, аптечка остаётся на карте.

### AMMO — боеприпасы

- Добавляет 35 патронов в запас текущего оружия.
- Боеприпасы пополняются для выбранного оружия, а не сразу для всех.

### DATA CORE — информационное ядро

- При сборе приносит 250 очков.
- Помогает увеличивать общий результат.

Предметы отображаются на карте разными цветами и имеют собственные визуальные обозначения, поэтому их можно различать во время сражения.

## Игровой мир

Арена имеет размер **2200 × 1700 игровых единиц** и значительно больше области, видимой на экране.

Особенности окружения:

- Промышленная сетка на поверхности.
- Препятствия, которые блокируют движение и снаряды.
- Камера, следующая за игроком.
- Случайно размещённые декоративные элементы.
- Появление врагов по краям карты.
- Размещение предметов в разных частях игрового мира.

Игрок может свободно исследовать арену, используя окружение для манёвров и изменения позиции во время боя.

## Рывок и выживание

Рывок активируется клавишей `Shift` и позволяет быстро переместиться в выбранном направлении.

- Скорость рывка: 900 единиц в секунду.
- Длительность: 0,15 секунды.
- Перезарядка способности: 1,5 секунды.
- Временная неуязвимость: 0,28 секунды.

Если игрок движется во время активации, рывок выполняется в направлении движения. Если персонаж стоит на месте, направление определяется прицелом.

Рывок полезен для уклонения от противников, выхода из окружения и быстрого перемещения по арене.

## Звуки и визуальные эффекты

Игра использует процедурно создаваемые звуковые эффекты и фоновую музыку.

Отдельные звуковые эффекты сопровождают:

- Стрельбу из каждого вида оружия.
- Попадания и атаки противников.
- Перезарядку.
- Сбор предметов.
- Рывок.
- Повышение уровня.
- Поражение игрока.

Визуальная составляющая включает частицы при выстрелах и уничтожении врагов, летящие гильзы, всплывающие очки, индикаторы здоровья противников, а также тряску экрана при сильных событиях.

Звуки и музыка генерируются непосредственно в Python-коде, поэтому для них не требуются отдельные аудиофайлы.

## Система очков

За уничтожение противников игрок получает очки. Их количество зависит от типа врага, текущей волны и серии убийств.

- Уничтожение противников увеличивает счётчик убийств.
- Серия быстрых убийств активирует комбо-множитель.
- Боссы приносят больше очков, чем обычные противники.
- Информационные ядра дают дополнительные 250 очков.

Игра сохраняет лучший результат в файле `outpost_zero_save.json`. Рекорд отображается в главном меню и после поражения.

## Интерфейс и игровые состояния

В игре предусмотрены следующие состояния:

- **Главное меню** — начало новой игры и отображение лучшего результата.
- **Игровой процесс** — сражения, сбор предметов и прохождение волн.
- **Пауза** — временная остановка игрового процесса.
- **Повышение уровня** — выбор одного из трёх улучшений.
- **Поражение** — отображение результата и возможность начать заново.

Когда здоровье игрока достигает нуля, текущая игра завершается. После этого можно начать новую попытку и постараться побить свой предыдущий рекорд.

## Установка и запуск

### Требования

- Python 3.11 или совместимая версия.
- Pygame 2.6.1.

### 1. Склонируй репозиторий

```bash
git clone https://github.com/GlebVPS7/Outpost-Zero.git
```

### 2. Перейди в папку проекта

```bash
cd Outpost-Zero
```

### 3. Установи необходимые зависимости

```bash
pip install pygame==2.6.1
```

### 4. Запусти игру

Если основной файл называется `main.py`:

```bash
py main.py
```

Если ты назвал основной файл `outpost_zero.py`, используй:

```bash
python outpost_zero.py
```

**Примечание:** игра запускается напрямую через `py main.py`.
